## 每次运行前记录

```bash
git rev-parse HEAD
git status --short --branch
uv --version
nvidia-smi --query-gpu=name,memory.total,driver_version --format=csv
```

如果模型或数据来自 Hub，尽量记录 revision，而不是只记录 `main`。如果当前命令没有显式指定 revision，至少在结果备注里写明这一点。

## 第一轮结果不要过度解释

- 一个 task、一个 episode 只能说明流程打通；
- 10 episodes/task 才适合看粗略成功率；
- 四 suite 完整结果才适合和公开 benchmark 表格比较；
- LIBERO-plus 成功率下降不自动说明模型“泛化能力差”，还要按扰动维度分析。
