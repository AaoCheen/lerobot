# 02：模型权重选择

## 推荐顺序

### A. 第一个：SmolVLA LIBERO checkpoint

```text
lerobot/smolvla_libero
```

这是已经针对 `lerobot/libero` 训练的 SmolVLA checkpoint，权重约 907 MB。适合先验证：

```text
Hub 下载 → policy 加载 → processor → MuJoCo LIBERO → success 统计
```

模型页：[lerobot/smolvla_libero](https://huggingface.co/lerobot/smolvla_libero)

### B. 第二个：Pi05 LIBERO 微调 checkpoint

```text
lerobot/pi05_libero_finetuned_v044
```

这是已经在 LIBERO 数据上微调过的 Pi05 checkpoint，权重约 7.47 GB。适合做主结果或高质量 VLA 对照。它不是从头训练，也不是只加载 `pi05_base` 的随机模型。

模型页：[lerobot/pi05_libero_finetuned_v044](https://huggingface.co/lerobot/pi05_libero_finetuned_v044)

评测 Pi05 时建议显式写：

```bash
--policy.n_action_steps=10
```

如果使用 `--policy.path`，checkpoint 的配置通常会一起读取；如果改用 `--policy.pretrained_path`，则必须自己补齐 Pi05 的 policy 配置。

### C. 第三个：XVLA LIBERO checkpoint

```text
lerobot/xvla-libero
```

这是另一个已经在 LIBERO 上训练/评测的 VLA，约 0.9B 参数，模型文件约 3.52 GB。它和 Pi05/SmolVLA 不是同一个架构，适合做跨架构对照。

模型页：[lerobot/xvla-libero](https://huggingface.co/lerobot/xvla-libero)

### D. 可选：Pi0-FAST LIBERO checkpoint

```text
lerobot/pi0fast-libero-v044
```

它也是 LIBERO checkpoint，但相机 key 与 LIBERO 环境的默认 key 不同，通常需要 `--rename_map`，所以不建议作为第一个实验。先完成 SmolVLA/Pi05，再研究它。

模型页：[lerobot/pi0fast-libero-v044](https://huggingface.co/lerobot/pi0fast-libero-v044)

## 起始权重和评测权重不要混淆

| 类型 | 示例 | 用途 |
| --- | --- | --- |
| 已训练 checkpoint | `lerobot/smolvla_libero` | 直接评测 |
| 已训练 checkpoint | `lerobot/pi05_libero_finetuned_v044` | 直接评测、二阶段适配 |
| 基础权重 | `lerobot/smolvla_base` | 后续自己微调 |
| 基础权重 | `lerobot/pi05_libero_base` | 后续复现 Pi05 全量微调 |

第一轮的目标是评测，不是训练。因此优先使用已训练 checkpoint。

## 对 LIBERO-plus 的使用方式

第一轮建议把同一个标准 LIBERO checkpoint 直接拿去两个环境：

```text
lerobot/smolvla_libero
    ├── env.type=libero       标准性能
    └── env.type=libero_plus  扰动鲁棒性
```

这样可以初步估计从标准 LIBERO 到 LIBERO-plus 的性能下降。不要先在 `lerobot/libero_plus` 上微调再声称是 OOD 泛化；那会改变实验问题。
