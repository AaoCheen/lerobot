# 01：环境准备

这一页只做环境检查和隔离，不跑 benchmark。

## 1. 确认自己在复现分支

在仓库根目录执行：

```bash
git branch --show-current
git status --short --branch
```

应该看到：

```text
dataset-notes
```

按当前协作约定，资料先放在 `dataset-notes`；以后由你手动合并到 `reproduce/my_branch1`。

## 2. 检查机器

```bash
uname -a
uv --version
nvidia-smi
```

没有 GPU 时不要立刻运行 Pi05；可以先只阅读命令或使用较小的 SmolVLA 做环境检查。

## 3. 设置无窗口渲染

服务器上通常没有显示器，先执行：

```bash
export MUJOCO_GL=egl
```

每次打开新终端都需要重新设置，或者把它加入自己的 shell 配置。

## 4. 为 vanilla LIBERO 建立独立 uv 环境

LIBERO-plus 会替换 `import libero` 对应的包，因此不要让两个环境共用同一个 `.venv`。先创建 vanilla LIBERO 环境：

```bash
export LIBERO_ENV=.venv-libero

UV_PROJECT_ENVIRONMENT="$LIBERO_ENV" uv sync --locked \
  --extra evaluation \
  --extra libero \
  --extra smolvla \
  --extra pi \
  --extra xvla
```

这里暂时把三个 VLA 所需的依赖一起装上，后面可以在同一个 vanilla 环境里切换 checkpoint。

验证 vanilla LIBERO：

```bash
UV_PROJECT_ENVIRONMENT="$LIBERO_ENV" uv run --no-sync python -c \
  "import libero, mujoco; print('libero=', libero.__file__); print('mujoco=', mujoco.__version__)"
```

## 5. 为 LIBERO-plus 建立另一个环境

```bash
export LIBERO_PLUS_ENV=.venv-libero-plus

UV_PROJECT_ENVIRONMENT="$LIBERO_PLUS_ENV" uv sync --locked \
  --extra evaluation \
  --extra libero \
  --extra smolvla \
  --extra pi \
  --extra xvla
```

按照仓库的 LIBERO-plus 文档，接着安装 plus fork：

```bash
mkdir -p third_party
git clone https://github.com/sylvestf/LIBERO-plus.git third_party/LIBERO-plus

UV_PROJECT_ENVIRONMENT="$LIBERO_PLUS_ENV" uv pip install \
  --python "$LIBERO_PLUS_ENV/bin/python" \
  "robosuite==1.4.1" bddl easydict mujoco wand scikit-image gym

UV_PROJECT_ENVIRONMENT="$LIBERO_PLUS_ENV" uv pip install \
  --python "$LIBERO_PLUS_ENV/bin/python" \
  --no-deps -e third_party/LIBERO-plus

UV_PROJECT_ENVIRONMENT="$LIBERO_PLUS_ENV" uv pip uninstall \
  --python "$LIBERO_PLUS_ENV/bin/python" hf-libero
```

LIBERO-plus 还需要单独的 `assets.zip`。从 [LIBERO-plus 数据集](https://huggingface.co/datasets/Sylvest/LIBERO-plus/tree/main)下载后，解压到 plus 包中的 `libero/assets/`。不要把这个大文件放进 Git 仓库。

验证 plus 环境：

```bash
UV_PROJECT_ENVIRONMENT="$LIBERO_PLUS_ENV" uv run --no-sync python -c \
  "import libero; print('libero-plus package=', libero.__file__)"
```

如果两个环境的 `libero.__file__` 指向相同位置，说明环境没有真正隔离，需要先停下来检查，不要继续评测。

## 6. 模型访问

SmolVLA 和 XVLA 通常可以直接下载。Pi05 使用 Gemma 许可的模型，若 Hub 提示需要许可，先在模型页面接受许可，再执行：

```bash
hf auth login
```

评测命令会自动下载 checkpoint；第一次下载前先确认磁盘空间和网络。
