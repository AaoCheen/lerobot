# 00｜仓库地图与核心概念

## 1. 你最常用的目录

~~~text
src/lerobot/
├── datasets/      LeRobotDataset、数据读取和数据工具
├── policies/      ACT、SmolVLA、Pi0、Pi05、GR00T 等 policy
├── processor/     observation/action 的预处理和后处理
├── envs/          LIBERO、Meta-World、RoboCasa 等仿真环境
├── configs/       train、eval、dataset、policy 配置
├── scripts/       lerobot-train、lerobot-eval 等命令
└── robots/        真实机器人接口（当前学习阶段先不看）

docs/source/
├── 数据集文档
├── policy 文档
└── benchmark 文档

examples/
├── dataset/       数据集读取示例
├── training/      训练示例
└── port_datasets/ 外部数据转换示例

docker/
└── Dockerfile.benchmark.*  不同 benchmark 的环境镜像
~~~

## 2. 一次训练的基本数据流

~~~text
LeRobotDataset
  → 取出图像、state、action、task
  → data processor 对字段、shape、归一化做处理
  → policy.forward(batch)
  → 计算 action loss
  → 反向传播更新参数
~~~

评测时没有专家 action 作为监督：

~~~text
仿真环境 reset
  → observation
  → processor
  → policy.select_action
  → action
  → 环境 step
  → 新 observation
~~~

## 3. 最重要的 CLI

~~~bash
lerobot-train --help

~~~

本学习路线主要使用：

~~~text
lerobot-train 训练和微调
lerobot-eval  仿真评测
~~~

## 4. 不要混淆这些对象

~~~text
task      任务目标，例如“把杯子放到盘子上”
episode   一次完整演示或一次评测 rollout
frame     一个控制时刻的 observation/action 记录
state     机器人当前状态
action    模型或专家下一步要执行的动作
policy    根据 observation 预测 action 的模型
benchmark 一组任务、环境、成功条件和评测协议
~~~

## 5. 初学者的第一张关系图

~~~
