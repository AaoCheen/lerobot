# 02｜数据集与训练输入

## 1. 训练数据应该是什么

LeRobot 用 LeRobotDataset 读取：

~~~text
图像
observation.state
action
timestamp
episode_index
task_index / task
~~~

LIBERO-plus 的典型单帧输入可以理解为：

~~~text
front image:  [3, 256, 256]
wrist image:  [3, 256, 256]
state:        [8]
action:       [7]
task:         一句自然语言
~~~

一次样本是否包含历史图像和未来动作，由 delta_timestamps 和 policy 配置决定。

详细说明见：

- [LeRobotDataset v3.0](../lerobot_dataset_research/01_format_and_shapes.md)
- [Hub 目录和读取 shape](../lerobot_dataset_research/05_HuggingFace数据集目录与LeRobotDataset读取.md)
- [LIBERO-plus 逐层解释](../lerobot_dataset_research/04_libero_plus_format_explained.md)

## 2. Dataset 不等于 Benchmark

~~~text
dataset      训练用的专家 demonstrations
benchmark    评测用的模拟环境和成功判定
~~~

评测时模型在线和环境交互，不是简单重放训练 episode。

## 3. 训练前必须核对

~~~text
dataset codebase_version
camera keys
state/action shape
state/action 含义和单位
相对动作还是绝对动作
FPS
task/language 字段
normalization stats
train/validation/test 划分
~~~

shape 相同也不代表语义相同。例如两个 [7] action 可能一个是末端位姿动作，另一个是关节动作。

## 4. 一个最小读取检查

~~~python
from lerobot.datasets import LeRobotDataset

dataset = LeRobotDataset(
    "lerobot/libero",
    episodes=[0],
)

sample = dataset[0]
for key, value in sample.items():
    if hasattr(value, "shape"):
        print(key, tuple(value.shape), value.dtype)
    else:
        print(key, type(value).__name__, value)
~~~

## 5. 数据问题和模型问题要分开

训练 loss 不下降，可能来自：

- dataset key 不匹配；
- task 没有正确传入；
- normalization 不一致；
- action 表示不一致；
- 视频解码或时间戳错误；
- batch shape 与 policy 预期不同。
